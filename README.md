# Neon Parry

네 방향에서 다가오는 사이버 위협을 패링하는 코어 방어 게임. HTML/CSS/JavaScript가 모두 `index.html` 하나에 들어 있습니다. 패키지 설치, 계정, 외부 리소스가 필요하지 않습니다.

## iPad에서 개발하고 실행하기

1. Safari에서 이 저장소의 `index.html`을 열고 연필(Edit) 버튼으로 수정합니다. 큰 수정은 저장소 화면에서 `github.dev` 편집기를 열어 진행할 수도 있습니다.
2. 변경 내용을 `main`에 커밋합니다.
3. Actions의 `Deploy game to GitHub Pages` 성공을 확인하고 Pages 주소를 Safari에서 엽니다. 변경 반영에는 시간이 걸릴 수 있습니다.
4. Safari 공유 메뉴의 ‘홈 화면에 추가’로 바로가기를 만들 수 있습니다. 오프라인 앱 설치 기능은 포함하지 않습니다.

첫 배포 전에 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택하세요. 공개 저장소는 GitHub Free의 Pages를 사용할 수 있습니다. 비공개 저장소는 요금제 지원 여부를 확인하세요. 기본 주소는 `https://qqock2e.github.io/NeonParry/`이며, 실제 주소는 Pages 설정과 성공한 배포 결과에서 확인하세요.

## 로컬 확인

`index.html`을 브라우저로 열거나 저장소에서 `python3 -m http.server 8000 --bind 0.0.0.0`를 실행합니다. 클라우드의 localhost는 iPad에서 직접 열 수 없습니다. iPad에서는 Pages 배포 주소를 사용하세요.

방향키/WASD 또는 플레이 영역의 해당 방향을 터치해 방어합니다. 터치는 스와이프와 구분하기 위해 손을 뗄 때 확정하며, 짧은 탭(180ms 이하)은 처음 누른 시점으로 판정합니다. 스와이프나 취소된 터치는 방어 입력으로 중복 처리하지 않습니다.

여러 적이 함께 접근하되 각 공격의 판정선 도착 시각을 예약합니다. 일반 적·트로이·웜 돌진 모두 최소 840ms 간격으로 도착해 ±360ms 방어 구간이 겹치지 않습니다. 적을 먼저 없애도 예약된 간격은 유지합니다. 기본 등장 간격은 활성 플레이 90초에 걸쳐 1.55초→0.84초(+0~0.12초 무작위)로 줄어듭니다. 특수 공격이 끼어들면 일반 적의 등장은 뒤로 밀릴 수 있습니다. 다른 속도의 적은 예약 시각에 맞춰 출현하므로 미리 화면에 보이지 않는 대기 상태가 있을 수 있습니다.

- **일반 방어:** 도착 시각 기준 ±360ms. 적의 외곽이 밝아지고, 각 라인의 짧은 눈금이 해당 적의 방어 가능 범위를 보여줍니다. 원형 점선은 기본 속도의 기준이며 실제 눈금은 적 속도에 맞춰 달라집니다.
- **정밀 패링:** ±100ms. 적 내부 게이지가 꽉 차는 순간이며 취약률 4%p 회복, 웜은 20%p 회복입니다(최저 0%).
- **헛방어:** 해당 방향 범위 안에 방어할 적이 없으면 취약률 +4%p. 방향별 300ms 대기 중 입력과 키 자동 반복은 무시합니다.
- **종료:** 취약률이 100%를 초과하면 즉시 종료합니다. 정확히 100%는 생존합니다.

### 위협과 해금

해금은 현재 게임의 방어/제거 횟수 기준입니다. 프록시 제거도 점수에는 포함되지만 스킬 충전에는 포함되지 않습니다.

| 위협 | 해금 | 피격 취약률 | 행동 |
| --- | --- | --- | --- |
| 바이러스 | 시작 | +14%p | 기본 마름모, 판정선까지 2.2초 |
| DDoS | 3회 | +24%p | 기본 원, 바이러스와 같은 속도·판정이며 피해만 높음 |
| 트로이 | 8회 | +34%p / 추가 침투 +8%p | 적에 13% 확률로 숨겨 붙음. 숙주 생성 시 외형 차이가 없음 |
| 컴퓨터 웜 | 15회 | +30%p | 중간 지점에 카운트 2~3으로 등장. 같은 라인에서 그만큼 적을 방어하면 가속 돌진. 정밀 패링은 −20%p |
| 랜섬웨어 | 25회 | +8%p | 판정선까지 1.25초. 피격 시 해당 방향의 일반 방어를 1.2초 잠금 |

트로이는 바이러스·DDoS·웜·랜섬웨어에 붙을 수 있습니다. 숙주를 방어하면 400ms 동안 무작위 다른 비보호 라인의 중간 지점으로 튕겨 나와, 일반 적보다 느리게 접근합니다. 다른 공격과 판정이 겹치지 않도록 중간에서 잠깐 대기할 수 있습니다. 숙주를 놓치면 금색 트로이가 코어에서 튕겨 나왔다가 700ms 뒤 다시 박혀 +8%p 추가 피해를 줍니다. 이 추가 침투는 판정선 밖의 후속 피해이며 일반 패링 대상이 아닙니다.

웜은 10~15초 간격으로 생성되며 동시에 최대 2마리가 대기합니다. 같은 라인에 대기 중인 웜은 중복 생성하지 않습니다. 카운트가 0이 되면 `!`로 바뀌고 예약된 시각에 맞춰 빠르게 가속합니다. 랜섬웨어 잠금 중에는 방향에 ×가 표시되며 방어 입력은 무시되고 헛방어 피해는 추가하지 않습니다. 다른 방향은 계속 조작할 수 있습니다.

### 시작 스킬

시작/재시작 전 화면에서 하나를 선택합니다. 일반 방어로 적 1체를 처치할 때마다 1칸 충전되며 최대 1회분만 저장합니다. 정밀 패링·트로이·웜 처치도 1칸입니다.

| 스킬 | 충전 | 효과 | 조작 |
| --- | --- | --- | --- |
| 백신 | 8체 처치 | 취약률 −32%p, 최저 0% | Space, 스킬 아이콘, 아무 라인에서 진행 방향 또는 반대 방향 스와이프 |
| 프록시 | 6체 처치 | 선택한 라인 적 전부 제거 + 5초간 그 라인 생성 차단 | Shift+방향키/WASD, 해당 라인 스와이프, 또는 스킬 아이콘을 누르고 방향 터치 |

프록시는 판정선·카운트·방어 타이밍과 관계없이 대기 중인 웜과 숨은 트로이까지 함께 정리합니다. 보호 라인은 일반 적·웜 생성과 트로이의 이동 대상에서 제외됩니다. 다른 라인의 적과 기존 예약 간격은 유지됩니다. 프록시로 제거한 적은 충전·정밀 회복·트로이 탈출을 발생시키지 않습니다. 랜섬웨어 잠금은 일반 방어에 적용되므로 충전된 프록시로 경로를 정리하는 것은 가능합니다.

일시정지 버튼/Escape, 백그라운드·창 이탈 시 자동 일시정지를 지원합니다. 일시정지 중에는 잠금·보호·스킬 관련 시간도 멈춥니다. 최고 방어 횟수는 브라우저에 저장하며, 새 게임에서는 해금·잠금·보호·충전이 초기화됩니다.

## 디자인 방향과 타격감

어두운 단색 화면, 파스텔 네온그린·핑크, 얇은 조준선과 플랫 패널을 유지합니다. Cyberpunk 2077의 HUD처럼 사선 `///`, 끊긴 선 `--`, 점선, 계기판 눈금을 참고합니다. 장식은 코너·구분선·판정 피드백에 한정하고 작은 부제목을 늘리지 않습니다. 과도한 발광, 그라데이션, 글래스모피즘, 화면을 가리는 효과는 피합니다.

- 중앙에는 후드·바이저·스카프 실루엣의 SVG 캐릭터가 있습니다. 방어 시 해당 방향으로 순간적으로 자세와 팔·방패가 바뀌며, 65ms 흰색 반짝임과 170ms의 접촉 자세 뒤 대기로 돌아갑니다. 부드러운 보간 대신 컷을 바꾸는 움직임입니다.
- 적은 두 조각이 반대로 회전·비틀리며 엇갈려 사라지고, 사선 베기와 파편이 짧게 남습니다. 정밀 패링은 파편과 접촉선이 더 강합니다.
- 흔들림은 입력 영역이 아닌 SVG 화면 내부에만 적용합니다. 방어 1.4, 정밀 패링 2.4, 피격 4 SVG 단위의 130ms 흔들림입니다.
- 소환 글리치는 생성 지점 주변에만 220ms 발생합니다. 코어 피격은 중앙 360ms 글리치와 취약률 표시의 신호 끊김, 게임오버는 620ms 이내의 화면 띠·제목 글리치를 사용하며 반복하지 않습니다.
- SVG 효과는 게임 시간으로 갱신되므로 일시정지 시 멈추고, 종료/재시작 시 정리됩니다. 종료 화면 CSS 효과는 짧게 재생 후 안정됩니다. `prefers-reduced-motion` 사용자는 흔들림·흰색 섬광·회전 파편·글리치 떨림 대신 자세와 짧은 페이드만 보게 됩니다.

## 작은 수익 실험

현재 결제, 광고, 분석 코드는 없습니다. 첫 실험은 무료 게임을 공개하고 선택적인 후원 링크를 추가하는 방식이 간단합니다. 후원 서비스를 정하고 실제 수령 계정을 준비한 뒤 링크를 연결하세요. 수익은 보장되지 않으며 서비스별 연령·지역·수수료·세금 조건을 확인해야 합니다. 광고는 트래픽과 광고 서비스 승인, 개인정보 고지 등 준비가 필요하므로 다음 단계에서 검토합니다.

## 검증

적별 피해, 트로이 은닉/숙주 처치/숙주 피격 분기, 웜의 라인별 카운트·가속·정밀 회복, 랜섬웨어 잠금과 복구, 스킬 선택·충전·사용·재시작, 프록시의 충전 제외와 소환 차단, 실제 터치 스와이프/탭 구분을 검증합니다. 시드가 고정된 300초 진행에서도 모든 위협 해금과 겹치지 않는 도착 예약, 이펙트 정리를 확인합니다.

데스크톱 브라우저 자동화로 네 방향 입력, 여러 적의 겹친 접근과 겹치지 않는 판정 시각, 진행에 따른 도착 간격 감소, 일반 방어/정밀 패링/회복, 헛방어 페널티와 입력 대기, 적의 게이지와 이동, 코어 충돌, 100% 초과 종료, 일시정지/재개, 재시작, 기록 보존 및 모바일 터치를 확인합니다. 이펙트 수명/정리, 네 방향 캐릭터 자세, 생성 지점에 한정된 글리치, 동작 줄이기 설정도 확인합니다. 실제 iPad Safari에서 터치 반응과 화면 전환도 별도 확인하세요.
