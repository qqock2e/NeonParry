# Neon Parry

네 방향에서 다가오는 사이버 위협을 패링하는 코어 방어 게임. HTML/CSS/JavaScript가 모두 `index.html` 하나에 들어 있습니다. 패키지 설치, 계정, 외부 리소스가 필요하지 않습니다.

## iPad에서 개발하고 실행하기

1. Safari에서 이 저장소의 `index.html`을 열고 연필(Edit) 버튼으로 수정합니다. 큰 수정은 저장소 화면에서 `github.dev` 편집기를 열어 진행할 수도 있습니다.
2. 변경 내용을 `main`에 커밋합니다.
3. Actions의 `Deploy game to GitHub Pages` 성공을 확인하고 Pages 주소를 Safari에서 엽니다. 변경 반영에는 시간이 걸릴 수 있습니다.
4. Safari 공유 메뉴의 ‘홈 화면에 추가’로 바로가기를 만들 수 있습니다. 오프라인 앱 설치 기능은 포함하지 않습니다.

첫 배포 전에 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택하세요. 공개 저장소는 GitHub Free의 Pages를 사용할 수 있습니다. 비공개 저장소는 요금제 지원 여부를 확인하세요. 기본 주소는 `https://qqock2e.github.io/NeonParry/`이며, 실제 주소는 Pages 설정과 성공한 배포 결과에서 확인하세요.

## 로컬 확인

`index.html`을 브라우저로 열거나 저장소에서 `python3 -m http.server 8000 --bind 0.0.0.0`를 실행합니다. 클라우드의 localhost는 iPad에서 직접 열 수 없습니다. iPad에서는 Pages 배포 주소를 사용하세요.

방향키/WASD 또는 플레이 영역의 해당 방향을 터치해 방어합니다. 한 번에 한 적만 존재하고, 그 적이 방어되거나 코어에 닿아 사라진 뒤에 다음 적이 생성됩니다. 방향은 무작위입니다. 시작 1.2초 뒤 첫 적이 나타납니다. 활성 플레이 90초에 걸쳐 등장 대기 간격이 1.1초→0.18초(+0~0.14초 무작위), 판정선 도달 시간이 2.3초→1.45초로 서서히 줄어듭니다. 일시정지 시간은 난이도 증가에 포함되지 않습니다.

- **일반 방어:** 판정선 기준 ±360ms. 화면의 두 점선 사이에 적 중심이 있으면 방어할 수 있습니다. 적 내부 게이지는 정확히 판정선에서 꽉 찹니다.
- **정밀 패링:** ±100ms. 방어와 함께 취약률 4%p 회복(최저 0%).
- **헛방어:** 선택한 방향의 방어 범위에 적이 없으면 취약률 4%p 증가합니다. 너무 이르거나 늦은 입력도 포함합니다. 적은 사라지지 않습니다.
- **코어 피격:** 놓친 적은 계속 이동해 충돌하며 취약률 20%p가 증가합니다.
- 방향별 300ms 입력 대기와 키 자동 반복 차단으로 연속 입력을 제한합니다. 대기 중 입력은 무시하며 이중 페널티를 주지 않습니다.
- 취약률이 정확히 100%면 생존하고, 100%를 초과하면 즉시 종료됩니다. 회복/헛방어가 있어 최종 값은 달라질 수 있습니다.

원(DDoS)과 마름모(바이러스)는 현재 같은 공격 규칙을 사용합니다. 최고 방어 횟수는 브라우저에 저장됩니다. 일시정지 버튼/Escape를 지원하며, 백그라운드 전환이나 창 포커스 이탈 시 자동 일시정지됩니다. 계속하기를 누르면 같은 위치에서 이어집니다.

## 디자인 방향

어두운 단색 화면, 파스텔 네온그린·핑크, 얇은 조준선과 플랫 패널을 유지합니다. Cyberpunk 2077의 HUD처럼 사선 `///`, 끊긴 선 `--`, 점선, 계기판 눈금을 참고하되 게임의 자산·서체·레이아웃을 복제하지 않습니다. 장식은 코너·구분선·판정 피드백에 한정하고 작은 부제목을 늘리지 않습니다. 앞으로 이펙트는 방어/정밀 패링/피격을 구별하는 짧은 신호를 중심으로 추가하며, 적·판정선·입력 방향의 가독성을 우선합니다. 과도한 발광, 그라데이션, 글래스모피즘, 화면을 가리는 효과는 피합니다.

## 작은 수익 실험

현재 결제, 광고, 분석 코드는 없습니다. 첫 실험은 무료 게임을 공개하고 선택적인 후원 링크를 추가하는 방식이 간단합니다. 후원 서비스를 정하고 실제 수령 계정을 준비한 뒤 링크를 연결하세요. 수익은 보장되지 않으며 서비스별 연령·지역·수수료·세금 조건을 확인해야 합니다. 광고는 트래픽과 광고 서비스 승인, 개인정보 고지 등 준비가 필요하므로 다음 단계에서 검토합니다.

## 검증

데스크톱 브라우저 자동화로 네 방향 입력, 단일 적 유지와 진행에 따른 속도 증가, 일반 방어/정밀 패링/회복, 헛방어 페널티와 입력 대기, 적의 게이지와 이동, 코어 충돌, 100% 초과 종료, 일시정지/재개, 재시작, 기록 보존 및 모바일 터치를 확인합니다. 실제 iPad Safari에서 터치 반응과 화면 전환도 별도 확인하세요.
