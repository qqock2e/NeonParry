# 보스 러쉬·도전과제·도감

## 보스 러쉬

Play → Boss rush / 보스 러쉬 → 난이도 → 백신 또는 미끼폴더 → Start.

일반 적은 생성하지 않습니다. 보스 등록 목록을 섞은 순환을 사용해 모든 종류를 경험할 수 있습니다. 현재 페이크 도메인과 디스-트로이를 포함하며, 이후 등록된 보스도 다음 순환에서 포함됩니다. 보스 접근·반응·분열·예고 패턴은 해당 보스 규칙을 따릅니다.

보스 완전 처치당 1점을 주고, **처치 후 점수만큼 %p 회복**합니다. 예: 5번째 처치 후 5%p, 20번째 처치 후 20%p. 취약률은 0 아래로 내려가지 않습니다. 기존 도메인 패턴 성공 5%p·디스-트로이 사이클 성공 20%p 회복은 별도로 유지됩니다.

보스 속도는 `기본 난이도 보스 속도 × (1 + 점수 × 0.01)`, 피격 피해는 `기본 난이도 피해 × (1 + 점수 × 0.015)`입니다. 반응 제한시간·분열 예고와 이동 시간에도 보스 속도를 적용합니다. 취약률 상승의 최종 소수점 반올림은 기존 규칙을 따릅니다. 단, 헛방어/잘못된 순서 입력의 4%p는 실제 코어 피격 배율을 적용하지 않습니다.

첫 보스 전 및 각 보스 종료 후 5초 휴식합니다. 휴식 시작 시 선택한 스킬이 완충되어 한 번 사용할 수 있습니다. 사용하지 않은 횟수는 쌓이지 않습니다. 전투 동안 충전되더라도 다음 휴식 전에는 사용할 수 없습니다. 백신은 29%p 회복하며 휴식 중의 둔화는 다음 보스 경고에서 해제됩니다. 미끼폴더 50포인트는 유지됩니다. 프록시는 선택할 수 없습니다.

휴식/전투 모두 메뉴·탭 이탈 등으로 정지되며 휴식의 5초도 함께 멈춥니다. 재도전은 점수·난이도 배율·실시간 전투 상태를 초기화합니다. 최고 기록은 난이도별 보스 처치 점수로 저장하며 무한 모드 기록에 섞이지 않습니다. 살아남은 도메인 도주는 처치가 아니므로 점수·처치 회복을 주지 않고, 휴식 후 같은 보스에 재도전합니다.

## 도전과제 — 총 18개

| 이름 | 조건 |
| --- | --- |
| (난이도) 클리어 ×4 | 해당 난이도 스테이지 5에서 보스를 처치하고 클리어 |
| 온리 에로우 · (난이도) ×4 | 스테이지 5를 실제 스킬 발동 없이 클리어 |
| 온리 퍼펙트 · (난이도) ×4 | 스테이지 5에서 모든 제거를 정밀 패링으로 달성하고 클리어 |
| 첫만남 | 무한 모드의 100점 보스를 완전 처치 |
| 사이버 사이코 · (난이도) ×4 | 해당 난이도 무한 모드 1,000점 도달 |
| 보스 공략 | 한 번의 보스 러쉬에서 20점 달성 |

난이도는 쉬움·보통·어려움·익스트림입니다. 온리 조건은 앞 스테이지들까지 누적하지 않고 **스테이지 5 시작부터 클리어까지** 검사합니다. 재도전하면 조건을 새로 추적합니다. 실패한 스킬 사용 시도는 실제 발동이 아니므로 온리 에로우를 깨지 않습니다.

온리 퍼펙트는 일반 적의 정밀 판정과 보스의 접근체/분열체 정밀 판정을 추적합니다. 숫자 반응처럼 도착 타이밍이 없는 도메인 본체는 제한시간 내 순서대로 입력하면 인정합니다. 프록시 제거는 정밀 패링이 아닙니다. 헛방어나 피격 자체는 제거 판정이 아니므로 이 조건을 깨지 않지만 일반 게임오버 조건은 그대로 적용됩니다. 백신·미끼폴더는 처치를 하지 않으므로 온리 퍼펙트와 양립할 수 있습니다.

도전과제는 칭호·성취 기록이며 능력치·점수 보너스가 없습니다. 기존 기록으로 증명되는 일반 스테이지 5 클리어와 무한 1,000점은 소급 반영합니다. 이전의 스킬 발동·정밀 여부·100점 보스 실제 승리는 저장되어 있지 않으므로 추정하여 지급하지 않습니다.

## 발견형 도감

도움말은 기본 조작법 / 적 도감 / 보스 도감 / 스킬 도감으로 나뉩니다. 탭은 터치·클릭과 좌우 화살표/Home/End 키로 이동합니다.

- 적: 실제 화면에 나타난 순간 발견합니다. 미래 도착 예약만으로는 발견되지 않습니다. 숨은 트로이는 숙주에 붙어 있을 때가 아니라 탈출/추가 침투가 드러날 때 발견합니다.
- 보스: 경고에 종류가 공개되는 순간 발견합니다. 보스 러쉬의 발견도 같은 도감에 반영됩니다.
- 미발견: 이름과 상세 설명을 숨기고 검은 실루엣, ?, 등장 조건만 표시합니다. 적의 등장 점수는 현재 플레이의 일반 제거 기준입니다. 보스는 100점 단위 전투 또는 보스 러쉬에서 만날 수 있습니다.
- 스킬: 시작 전 선택에 필요한 정보이므로 처음부터 모두 공개합니다. 실제 아이콘과 사용 조건을 표시합니다.
- 원본 도형은 실제 적의 `shapePath`와 보스/스킬 아이콘을 사용합니다. 피해 수치는 쉬움 기준이며 상위 난이도/보스 러쉬 배율은 별도 적용됩니다.

## 저장·구현 위치

`neon-parry-achievements`, `neon-parry-discoveries`, `neon-parry-rush-bests`를 localStorage에 저장합니다. Pages·itch.io·Electron은 origin이 달라 기록을 자동 공유하지 않습니다. 비공개 탐색·임베드에서 저장이 차단되어도 현재 세션의 플레이와 도감은 동작하지만 재접속 시 유지되지 않을 수 있습니다.

`src/renderer/js/game.js`는 모드·전투·판정 추적, `features.js`는 도전과제·발견·탭 도감, `menu.js`는 선택과 목록 화면을 담당합니다. `BOSS_TYPES`가 보스 러쉬와 보스 도감의 등록 원본입니다.
