# 듀얼

왼쪽은 내 경기장입니다. 1대1과 CPU 연습은 오른쪽에 같은 크기의 상대 경기장을 표시합니다. 3~8인 친구방에서는 오른쪽에 상대 경기장을 작게 모아 보여 줍니다. 살아 있는 상대 화면을 누르면 공격 대상을 바꿀 수 있습니다.

## 시작과 조작

`npm run dev:duel` → `http://127.0.0.1:8000` → **Play → Duel / 듀얼**.

- **랜덤 매칭:** 같은 서버에서 1대1 상대를 찾습니다.
- **친구 초대:** 코드를 공유하고 2~8명이 모인 뒤 모두 준비를 누르면 시작합니다.
- **CPU 연습:** 서버 없이 입문·대등·숙련 상대와 연습합니다.

방향키/WASD로 패링합니다. Shift와 방향키/WASD를 함께 누르면 바이러스를 직접 쏩니다. Space나 공격 버튼으로 공격을 선택한 뒤 방향을 입력할 수도 있습니다. 터치는 경기장 구역 탭으로 패링, 그 구역의 세로/가로 방향 쓸기로 공격합니다.

## 기본 규칙

- 공격은 플레이어가 입력할 때만 발사됩니다. 새 공격 속도는 +15%에서 시작해 16초에 +75%, 76초에 +150%에 도달합니다. 같은 수비자에게 들어가는 공격은 520ms 이상 간격을 둡니다.
- 연속 적중 피해는 15 → 20 → 25%p입니다. 상대가 내 공격을 막으면 연속 적중이 초기화됩니다. 패링에 실패하면 내 취약률이 4%p 오릅니다.
- 수동 공격은 에너지 1칸을 씁니다. 최대 3칸, 시작 2칸입니다. 충전 속도는 기본(1.8초당 1칸)의 1.25배에서 시작해 100초에 2.5배에 도달합니다. 정밀 패링은 0.5칸을 더 채웁니다.
- 취약률 100% 또는 기권으로 탈락하면 남은 경기를 볼 수 있습니다. 마지막 생존자가 승리하며, 마지막 생존자들이 같은 판정에 함께 탈락하면 무승부입니다.

## 업그레이드

시작 8초 뒤 무작위 선택지 3개가 나옵니다. 고른 뒤 12초가 지나면 다음 선택지가 나옵니다. 아직 선택하지 않은 카드가 있으면 고를 때까지 남습니다. 경기장 위 버튼을 누르거나 1~3번 키로 하나를 고릅니다. 추가 적을 보낼 확률, 공격·충전 속도, 정밀 패링 보너스, 즉시 수리 효과가 후보이며 수치도 매번 달라집니다. 플레이어마다 선택지가 따로 추첨됩니다. 능력은 100%까지 중첩됩니다. 추가 바이러스 확률은 50%가 최대입니다. 최대치에 도달한 능력은 선택지에서 빠집니다. 공격 피해, 패링 충전, 정밀 패링 시 수리 확률도 선택지로 나옵니다.

공격 효율과 코어 장갑이 100%에 도달하면 각각 공격당 에너지와 상대에게 받는 피해가 절반이 됩니다. 헛방어 피해 감소가 100%에 도달하면 대전 중 헛방어 피해가 0이 됩니다.

추가 적은 해당 업그레이드를 고른 플레이어가 공격할 때 확률에 따라 함께 발사됩니다. 트로이를 패링하면 반대쪽에서 한 번 더 들어오고, 파란 웜은 제자리에서 대기하다가 같은 방향의 적을 패링해 숫자가 0이 되면 돌진합니다. 주황 피싱은 미끼 반대편에 드러나는 본체를 막아야 합니다. 공격 속도 업그레이드는 고른 플레이어의 새 공격부터 적용됩니다. CPU는 연습 상대의 기본 공격과 패링을 사용합니다.

## 보스전

서로 공격할 수 있는 시간이 60초 지나면 모두 같은 보스와 각자 경기장에서 싸웁니다. 페이크 도메인과 디스-트로이가 번갈아 나옵니다. 보스전 중에는 상대 공격과 능력 선택이 멈춥니다. 먼저 끝난 사람은 다른 사람의 전투를 볼 수 있고, 모두 끝나면 함께 대전을 재개합니다. 이미 날아가던 공격은 멈췄던 지점에서 이어집니다.

## 온라인 판정과 서버

온라인은 CPU 연습과 같은 규칙 엔진을 서버에서 실행합니다. 패링 모션은 입력 즉시 재생하고, 성공 여부와 피해는 서버 상태로 표시합니다. 서버가 확인한 왕복 지연의 절반을 최대 120ms까지 수신 시각에서 보정합니다. 기본 패링 창은 도착 시각 기준 ±360ms이며 정밀 창은 ±100ms입니다. 클라이언트가 주장하는 시각은 사용하지 않습니다.

전투 상태는 SSE로 보내며, 공격·패링·피해 등 변화가 있을 때와 연결 확인용 갱신 때 전송합니다. 경기장 이동은 서버 시각에 맞춰 브라우저가 그립니다.

다른 사람과 대전하려면 참가자 모두 같은 공용 서버를 사용해야 합니다. 랜덤 매칭은 그 서버의 대기자 중에서 고르며 실력 등급·지역을 구분하지 않습니다. [서버 실행 안내](SERVER.md)를 참고하세요.

연결 단절 후 15초 안에 복귀하지 않으면 기권으로 처리됩니다. 직접 나가기 역시 기권입니다. 친구방은 종료 후 남은 참가자가 다시 준비하면 재대결합니다. 랜덤 매칭은 종료 후 다음 상대 찾기로 다시 대기합니다. 새로고침 후 토큰 복구·영구 전적·랭킹은 제공하지 않습니다.
