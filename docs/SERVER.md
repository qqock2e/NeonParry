# 서버 실행 안내

## 서버를 직접 해야 하나요?

다른 사람과 온라인 대전을 하려면 **운영자가 모두 함께 쓰는 서버 하나**를 실행해야 합니다. 플레이어가 각자 서버를 켜는 방식은 아닙니다. CPU 연습·기존 싱글플레이에는 서버가 필요 없습니다.

게임 화면과 대전 API를 한 프로세스에서 제공하도록 만들었습니다. 참가자들은 그 서버의 같은 주소를 열고 랜덤 매칭 또는 친구 초대방을 사용합니다. 같은 서버에 대기자가 두 명 이상 있어야 랜덤 매칭이 잡힙니다.

## 내 컴퓨터에서 먼저 확인

Node.js 22.12 이상을 설치한 다음 저장소 폴더에서 실행합니다. Electron 패키지 설치는 웹 서버 실행에 필요하지 않습니다.

```sh
npm run dev:duel
```

브라우저에서 `http://127.0.0.1:8000`을 두 탭으로 열고, 각각 **Play → 듀얼 → 랜덤 매칭**을 누르세요. 서로 연결되고 3초 뒤 시작합니다. 종료는 터미널의 Ctrl+C입니다. 이 주소는 내 컴퓨터에서만 접속합니다.

## 같은 와이파이의 휴대폰·태블릿에서 확인

서버를 켤 컴퓨터의 내부 IP를 네트워크 설정에서 확인합니다. 아래 `192.168.0.10`은 예시이므로 실제 IP로 바꾸세요.

```sh
HOST=0.0.0.0 PORT=8000 \
ALLOWED_ORIGINS=http://192.168.0.10:8000 \
npm run dev:duel
```

두 기기를 같은 와이파이에 연결하고 모두 `http://192.168.0.10:8000`을 엽니다. 컴퓨터 방화벽이 묻는 경우 이 서버의 같은 네트워크 연결을 허용합니다. 서로 다른 서버를 켜면 매칭되지 않습니다. 이 단계는 인터넷 공개 서버가 아닙니다.

## 인터넷에서 누구나 접속하게 하기

계속 실행되는 Node.js 또는 Docker 호스트와 HTTPS 주소가 필요합니다. 가장 간단한 배포 설정은 다음과 같습니다. 특정 호스팅 계정 생성이나 유료 배포는 이 변경에서 수행하지 않았습니다.

1. Node.js/컨테이너 실행을 지원하는 호스트에 이 저장소를 연결하거나 업로드합니다.
2. Node.js 22.12 이상을 선택하고 시작 명령을 `npm run start:server`로 지정합니다. 웹 서버는 외부 패키지를 사용하지 않아 별도 빌드 명령이 필요 없습니다.
3. 환경변수 `ALLOWED_ORIGINS`를 실제 공개 페이지 주소로 지정합니다. 예: `https://neon-parry.example.com`. 끝의 `/`나 페이지 경로는 넣지 않습니다.
4. 호스트가 제공하는 HTTPS 주소와 포트 연결을 설정합니다. 서버는 기본 `0.0.0.0:8080`에서 실행하며, 호스트가 제공하는 `PORT`가 있으면 그 값을 사용합니다.
5. 공개 주소의 `/health`에서 `status: "ok"`가 나오고 게임 첫 화면이 열리는지 확인합니다. 두 기기에서 같은 주소로 랜덤 매칭을 실행합니다.

게임과 API가 같은 주소이므로 플레이어는 서버 주소를 따로 입력할 필요가 없습니다. 설정을 바꾸면 서버를 재시작합니다. 현재 방·매칭은 서버 메모리에 있으므로 **인스턴스는 한 개**로 운영합니다. 서버 재시작·절전·자동 중지 시 진행 중인 경기는 사라집니다.

중간 프록시를 직접 설정한다면 SSE 응답 버퍼링을 끄고 지속 연결을 허용합니다. HTTPS는 호스트의 프록시에서 처리하고 Node 서버로 연결하면 됩니다.

Docker를 사용한다면 저장소 루트에서:

```sh
docker build -f backend/Dockerfile -t neon-parry-server .
docker run --rm -p 8080:8080 \
  -e ALLOWED_ORIGINS=https://neon-parry.example.com \
  neon-parry-server
```

예시 도메인은 실제 주소로 바꾸세요. 컨테이너도 게임·대전 API를 함께 제공합니다.

## GitHub Pages를 계속 쓰려면

GitHub Pages는 HTML·CSS·JS 화면 파일만 제공하고 Node 대전 서버를 실행하지 않습니다. 기존 Pages 주소를 계속 쓰려면 위 서버를 따로 실행한 뒤 다음 두 가지를 연결합니다.

- 대전 서버 `ALLOWED_ORIGINS`: `https://jooyoungfe.github.io`를 포함합니다. 통합 서버 페이지도 사용하려면 두 origin을 쉼표로 나열합니다.
- GitHub 저장소 **Settings → Secrets and variables → Actions → Variables**의 `NEON_API_BASE_URL`: 실제 HTTPS 대전 서버 주소를 넣고 Pages 워크플로를 다시 실행합니다.

예: `ALLOWED_ORIGINS=https://neon-parry.example.com,https://jooyoungfe.github.io`. `/NeonParry/` 같은 경로는 origin에 넣지 않습니다. 한 서버에서 화면까지 제공하는 방식을 쓰면 Pages와 이 추가 설정은 필요 없습니다.

API만 별도로 실행하는 기존 명령은 `npm run start:backend`입니다. 공개 설정에는 비밀번호나 참가 토큰을 넣지 않습니다.
